- แสดงผลแบบเดียวกับ Counter EA:
  - ป้าย `R+2.31 | S+2.05` เหนือ High (SELL) / ใต้ Low (BUY) เมื่อ Z ตัวใดตัวหนึ่งเกินเกณฑ์ T2 → มีสีเมื่อถึงระดับ T2 / T3 / T4 ตามกฎของ EA (รวมเงื่อนไข Z_float) ส่วนสีเทาคือถึงเกณฑ์ไม่ครบ
  - ป้าย Z_float `F+1.23` (แท่งปัจจุบันแสดงเสมอ)
  - เส้นแนวนอนระดับ Z (เส้นถดถอย / SMA20 ± เกณฑ์ T2) + ป้าย Z สดที่ขอบขวา
  - เส้นย้อนหลังทุกแท่งเปิดได้ด้วย `InpShowHistLines` (ค่าเริ่มต้นปิด)
- 📅 ตารางอัตราการเกิดรายเดือน (มุมขวาล่าง):
  - % ของแท่งที่ Z (ที่ High / Low) เกิน 2.0 / 2.5 / 3.0 และ % ที่ทั้งคู่เกิน 2.5
  - ค่า Z ที่ top 1% / 0.3% / 0.1% ของแต่ละเดือน
  - บรรทัดล่างสุดคือเกณฑ์ปรับตามตลาดตอนนี้ และบอกว่าเกณฑ์คงที่ 2.5 / 3.0 / 3.5 เท่ากับ top กี่ %
- `InpThrMode = PCT`: เกณฑ์ปรับตามตลาด
  - T2 / T3 / T4 = ค่า Z สุดขั้วที่ top 1% / 0.3% / 0.1% ของแท่งย้อนหลัง `InpPctDays` = 20 วัน (M15 ≈ 1,920 แท่ง)
  - คำนวณจากแท่งที่ปิดแล้วเท่านั้น จึงไม่มองอนาคต
- `InpSigmaMode = RANGE`: ตัวหาร σ จากช่วงแท่ง (Parkinson)
  - ปรับสเกลด้วยค่าเฉลี่ยถ่วงของ σ ราคาปิด ÷ σ ช่วงแท่ง เพื่อให้ระยะยาวเท่ากับโหมดราคาปิด
  - ช่วงที่ไส้ยาวขึ้น ตัวหารจะโตตาม Z จึงไม่พองเกินจริง
- ยังไม่มีผลกับ EA: ใช้ทดลองดูว่าโหมดไหนทำให้อัตราการเกิดรายเดือนคงที่ที่สุด แล้วค่อยย้ายเข้า EA

### Context Indicator v2.00 — Z หลายนิยาม
- ลบเส้นชุดเก่าทั้งหมด (TF ใหญ่ / VWAP / Keltner / วันก่อน / เลขกลม / EMA200) เพราะไม่ได้วัดแบบเดียวกับ Z
- นิยามเดียวทุกเส้น: Z = (ราคา − เส้นกลาง) ÷ ค่าเบี่ยงเบนปกติรอบเส้นนั้น, หน้าต่าง 20 แท่ง = แท่งปิด 19 แท่ง + ราคาที่วัด (เหมือน EA)
  - R ถดถอย / S SMA20 (เหมือน EA) + ใหม่: Q ถดถอยโค้ง (กำลังสอง), M Median + MAD, V Speed (เทียบราคาปิด 4 แท่งก่อน ÷ σ√4), E EMA20 + SD แบบ exponential
  - วาดเส้นกลาง Q / M / E (แถบ ± 2σ เปิดได้ทีละเส้น)
- ป้ายแนวนอนบนแท่งที่ Z_reg หรือ Z_SMA ที่ High / Low เกิน ±2.00: `R S | Q M V E`
  — ป้ายที่ใกล้กันเรียงเป็นชั้นตามความกว้างตัวอักษรจริงบนจอ ไม่ซ้อนกัน (จัดใหม่เมื่อซูม / เลื่อน)
- ตารางสถิติมุมล่างซ้าย: ทุกแท่งในประวัติที่ |Z| > 2.00 แยกตามนิยาม → % กลับแตะเส้นภายใน 8 แท่ง + ระยะไปต่อสูงสุดเฉลี่ย

### Counter EA v12.80 — ค่าสุดขั้วนับจากราคา, Z*, ค่าโหนดจริง, ติดตามต่อหลังเข้าไม้
- **"ไม่มีค่าสุดขั้วใหม่" นับจากราคา:** ตัวจับเวลา T2 / T3 เริ่มนับใหม่เมื่อ Bid ทำ High (SELL) / Low (BUY) ใหม่ระหว่างเฝ้า เกินของเดิม `InpNoNewExt_Pts` = 100 จุด (แทน `InpNoNewExtEps` ที่วัดเป็น Z)
  - เหตุผล: Z_SMA มีเพดาน √(n−1) = 4.36 เพราะราคาปัจจุบันอยู่ในหน้าต่าง ที่ Z ≈ 4 ราคาต้องขึ้นอีกประมาณ 0.15σ Z ถึงจะขยับ 0.01 ทำให้ EA เคยยิงไม้สวนทั้งที่ราคายังพุ่งอยู่
  - Z สุดขั้วระหว่างเฝ้ายังจำไว้ใช้กับกฎในแท่ง (T3/T4 เข้าใหม่ต้อง Z สูงกว่าเดิม) และใช้บันทึก
- **Z\* = Z_SMA แบบไม่มีเพดาน** = Z · √(n ÷ (n − 1 − Z²)) = ระยะจากค่าเฉลี่ย 19 แท่งก่อน ÷ SD ของ 19 แท่งนั้น
  - ตัวอย่าง: Z 2.5 → 3.1, 3.0 → 4.2, 3.5 → 6.0, 4.0 → 10.3
  - แสดงบน Dashboard, ป้าย Z สด และป้ายบนแท่ง (`R+x | S+x | S*+x`) ยังไม่ใช้เป็นเกณฑ์เข้าไม้
- **ค่าโหนดจริง:** Z_reg / Z_SMA / Z\* ที่ราคาโหนด และโหนดต่ำกว่ายอดของการเฝ้าเท่าไร (ΔZ / จุด, + = ยอดที่ต่ำลง) แสดงใน tooltip และ CSV
- **ติดตามต่อหลังเข้าไม้ (Tick Replay):** ตามต่ออีก `InpPostTrack_Min` = 60 นาทีแม้ไม้ปิดแล้ว บันทึก:
  - Z_SMA / Z\* สูงสุดในทิศของการกระชาก
  - ระยะสวนสูงสุด / ระยะไปทางกำไรสูงสุด (จุด)
  - เวลาจนกว่า Z_SMA กลับถึง `InpPostBackZ` = 1.0
- CSV เพิ่มคอลัมน์ `z_sma_star, ext_zsma_star, node_zreg, node_zsma, node_zsma_star, node_lh_dz, node_lh_pts, post_min, post_max_zsma, post_max_zsma_star, post_max_adv_pts, post_max_fav_pts, post_back_z_sec`
