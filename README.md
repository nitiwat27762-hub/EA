### Counter EA v9.00
- C1 = Limit ที่ระดับ Z: ภายในแท่งเดียวกัน Z ขึ้นกับราคาปัจจุบันตัวเดียว → คำนวณราคาที่ Z ถึงเกณฑ์ครั้งเดียวต่อแท่ง (bisection)
  ว่าง + เลยนาทีแรก + ไม่ใช่แท่งข่าว + สเปรดผ่าน → วาง Sell Limit / Buy Limit พร้อมกัน (OCO), ขึ้นแท่งใหม่ย้ายไประดับใหม่,
  ราคาเลยระดับอยู่แล้วรอกลับก่อนวาง — ยกเลิกการจับเวลา No new high/low
- ระบบเงา: ยึดราคา C1 → กาง C2 / C3 / C4 (3,500 / 6,500 / 9,000 จุดจาก C1, ไม่มีออเดอร์จริง)
  ไม้ชน SL แล้วราคาวกกลับถึง C1 → สวนที่ C1 ด้วย Lot ของระดับลึกสุดที่ราคาแตะ (R2 / R3), เข้าซ้ำได้เมื่อไปลึกกว่าเดิมเท่านั้น
  แตะ C4 → ตามน้ำทันที; จบรอบเมื่อไม้ปิดแบบไม่ใช่ SL / C4 ปิด / รอเงาเกิน 30 นาที
- ตามน้ำปกติ (input เปิด/ปิด): Z_reg > 2.4 และ Z_SMA 0.0–1.0 → BUY (สมมาตรฝั่ง SELL), TP/SL/ไล่จี้/ตัด 60 วิ เหมือน C1
- ทำงานทีละรอบ: รอบสวน / ไม้ข่าว / ตามน้ำปกติ ใช้ล็อกเดียวกัน
- เส้นระดับ Limit C1 รายแท่ง + บันไดเงาของแต่ละรอบ; Tick Replay จำลอง Limit / เงา / ตามน้ำปกติ และสรุปผลแยก C1 / R2 / R3 / C4 / ตามน้ำ / ข่าว
